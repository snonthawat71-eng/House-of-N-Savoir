# ฟอนต์ Narin (ใช้กับ Code และ Name บนฉลาก FO Label)

Narin เป็นฟอนต์ลิขสิทธิ์ของ Ahmet Altun ต้องซื้อก่อนใช้งาน
(MyFonts / Fontspring — ราคาประมาณ $19 ต่อน้ำหนัก หรือ $159 ทั้งชุด)

เมื่อซื้อแล้ว ให้แปลงเป็นไฟล์เว็บแล้ววางไว้ในโฟลเดอร์นี้:

| ไฟล์ที่ต้องมี | ใช้กับ |
|---|---|
| `Narin-Regular.woff2` (และ `.woff`) | Code / Name ปกติ |
| `Narin-Light.woff2` (และ `.woff`) | ถ้าต้องการน้ำหนักบางลง |

วางไฟล์เสร็จ ฉลากจะเปลี่ยนไปใช้ Narin เองทันที ไม่ต้องแก้โค้ด

**ตอนนี้ยังไม่มีไฟล์** ระบบจึงใช้ Urbanist แทนไปก่อน (หน้าตาใกล้เคียง เป็นเรขาคณิตเหมือนกัน)
