# ฟอนต์ Narin (ใช้กับ Code และ Name บนฉลาก FO Label)

Narin เป็นฟอนต์ลิขสิทธิ์ ต้องซื้อก่อนใช้งาน — ไฟล์ในโฟลเดอร์นี้มาจากที่เจ้าของส่งให้

| ไฟล์ | ใช้กับ | สถานะ |
|---|---|---|
| `Narin-Regular.woff2` | Code / Name บนฉลาก | ✅ มีแล้ว |
| `Narin-Light.woff2` | น้ำหนักบาง (ยังไม่ได้ใช้ที่ไหน) | ยังไม่มี |

ถ้าวันหลังอยากใช้น้ำหนักบาง ให้เอาไฟล์ `Narin-Light.woff2` มาวางที่นี่
แล้วบอกให้เพิ่ม `@font-face` น้ำหนัก 300 ใน `src/index.css`

ถ้าไฟล์หายไป ฉลากจะถอยไปใช้ Urbanist ให้เองโดยไม่พัง
