# รูปสัญลักษณ์อันตราย GHS

วางไฟล์รูปไว้ในโฟลเดอร์นี้ ตั้งชื่อตามตารางให้ตรงเป๊ะ (ตัวพิมพ์ใหญ่ นามสกุล .png)

| ชื่อไฟล์ | สัญลักษณ์ |
|---|---|
| `GHS01.png` | ระเบิดได้ |
| `GHS02.png` | ไวไฟ (เปลวไฟ) |
| `GHS03.png` | ช่วยให้ไฟลุก |
| `GHS04.png` | ก๊าซอัดความดัน |
| `GHS05.png` | กัดกร่อน |
| `GHS06.png` | พิษร้ายแรง (หัวกะโหลก) |
| `GHS07.png` | ระคายเคือง (เครื่องหมายตกใจ) |
| `GHS08.png` | อันตรายต่อสุขภาพ |
| `GHS09.png` | เป็นพิษต่อสิ่งแวดล้อม |

ข้อแนะนำ:
- พื้นหลัง **โปร่งใส** กรอบแดงเต็มรูป (ไม่ต้องเว้นขอบขาวรอบ)
- รูปสี่เหลี่ยมจัตุรัส อย่างน้อย **600 × 600 px** เพื่อให้คมตอนพิมพ์
- ไฟล์ไหนยังไม่ใส่ ระบบจะวาดเป็นกรอบแดงเปล่าแทนชั่วคราว ใช้งานได้ไม่พัง

ส่งครบกี่ไฟล์ก็ได้ — ที่ยังไม่ส่งก็ยังเลือกได้ แค่จะขึ้นเป็นกรอบเปล่าจนกว่าจะใส่ไฟล์
